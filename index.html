APEX TERMINAL — COMMAND REFERENCE

Type a command in the amber bar and press ENTER (<GO>). Commands are not case-sensitive.

TICKER <GO>Load a security — e.g. AAPL, NVDA, SPX, EURUSD, BTC, CL1
DESSecurity description & key statistics F2
GPPrice graph — line or candles, 1D→5Y F3
NNews wire for the loaded security F4
MOSTMost-active movers, ranked by day change F5
WEIWorld equity indices, FX, commodities, crypto F6
COMP TICKEROverlay a comparison on the graph (indexed % return) — e.g. COMP MSFT. Up to 3.
CLRClear all comparison overlays
W ADD TICKERAdd a security to the watchlist · W DEL TICKER removes it
HELPThis screen F1

All market data on this terminal is simulated in the browser — a deterministic random-walk engine with live ticks. No external feed, no network calls.
